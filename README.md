# Reth Jaren Hijapon | OJT Portfolio

Personal portfolio website of Reth Jaren A. Hijapon, a fourth-year BSIT student at the University of the East, Caloocan, and a TESDA NC II Computer Systems Servicing holder seeking an OJT in IT Support.

## Sections

- About Me
- Technical Skills
- Projects and Achievements
- Certificates
- Contact form

## Built With

- HTML, CSS, and JavaScript
- Netlify for hosting
- A Netlify Function with Nodemailer for the contact form

## Project Structure

```
html/                 Main page (index.html)
css/                  Stylesheets
js/                   Scripts and animations
images/               Photos and graphics
documents/            Resume and certificates
netlify/functions/    Contact form backend
```

## Running Locally

```bash
npm install
npx netlify dev
```

Or open `html/index.html` directly in a browser to view the page without the contact form.
